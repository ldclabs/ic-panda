# dMsg 桌面客户端体验走查

2026-11-19，在 macOS arm64 上走查桌面版 1.5.9，代码起点为 `75aee602`。使用 Electron 45.2.3、隔离配置和合成账户。检查了 10 个主视图、设置的 13 个子页，以及首次使用、锁定、独立审批和系统交互。下列结论针对本地客户端。

## 已修复

| 维度 | 复现时用户看到什么 | 修改后的行为 |
| --- | --- | --- |
| 信息架构 | 在 760 像素宽的法语窗口打开反馈，设置导航仍显示最前面的几个入口。13 项内容宽 1,997 像素，可用宽度为 696 像素。通过链接进入智能体审计也看不到当前页签。 | 窄窗设置显示当前子页名称，展开可以选择全部 13 项。智能体页签在空间不足时换行，正常宽度保持单行。 |
| 用户流程 | 在保险库输入标题后切换条目类型，标题和字段立即清空。编辑时按切页快捷键也会直接离开表单。 | 更换类型或关闭有改动的条目时，先让用户选择继续编辑或放弃。键盘焦点落在「继续编辑」。保存期间锁住表单，应用内切页、后退和命令面板快捷键尊重当前弹窗，锁定快捷键仍可用。 |
| 操作效率 | 查看付款记录后去文件页，再用侧栏快捷键返回，会回到会员首页。钱包概览滚到底部再点「成员与安全」，第一眼看到的是底部的旧激活付款。 | 会员、名称和付款进入窗口导航历史，支持前进、后退和返回原页。名称邀请与查询返回到名称页。切换钱包或钱包页签，从新内容顶部开始。锁定的钱包页提供与其他受保护页面一致的登录或解锁操作。 |
| 反馈机制 | 查找一个名称后，输入另一个名称，旧名称的注册操作还在。窄窗的空归档只剩搜索框和空白，已发邮件读取失败时缺少就地重试。 | 改词立即撤下旧结果和操作，晚到的报价或错误只属于发起它的查询。当前查询失败可保留输入重试。空邮箱在窄窗使用可用高度，已发邮件的错误、重试和空态随对应列表显示。 |
| 视觉层级 | 法语智能体事件页的轮询状态占据标题右侧，说明文字被挤成窄列。直接打开已知钱包时，本地列表尚未收录它，选择框里可能只剩箭头。 | 轮询状态移到说明下方。钱包详情返回后，即使列表暂缺，也显示正在查看的钱包名称。 |
| 组件一致性 | 可访问性树中，保险库密码框没有名称，名称查询框只叫「@」，展开侧栏的同步按钮没有名称。阿拉伯语命令面板中的操作箭头与实际方向键不一致。 | 秘密输入统一关联本地化标签，自定义字段改名后读屏名称随之更新。名称查询有常驻标签和关联的错误说明，收件箱页签组和同步按钮有可读名称。阿拉伯语用左键进入更多操作、右键返回，提示与图标一致。 |

设备配对也有一处影响知情确认的问题。中文预览里原先直接显示 `Administrator`、`ContentSign` 和 `VaultUnlock`。设备列表、权限编辑、配对、设备替换和最终审批现在使用本地化的角色与权限名，沿用客户端已有译法。最终审批的技术详情保留原始权限标识。名称转移邀请在锁定时打开，会等到解锁再交给确认表单。

浅色选中行的辅助文字改用现有的次级文字色。按设计色值计算，文字与选中底色的对比度从 4.13:1 提升到 5.63:1。

## 复现入口

在桌面包目录完成 `pnpm build` 后运行以下命令。Electron 使用临时配置，业务操作指向测试数据。

| 命令 | 核对内容 |
| --- | --- |
| `DMSG_DESKTOP_SMOKE=navigation node scripts/smoke.mjs` | 模态表单里的快捷键、草稿保留、RTL 命令面板、名称查询晚到的回复、前进后退、窄窗导航和收件箱重试。 |
| `DMSG_DESKTOP_SMOKE=ux node scripts/smoke.mjs` | 主视图、欢迎流程、锁定、钱包内解锁，以及解锁后继续处理名称邀请。 |
| `DMSG_DESKTOP_SMOKE=pairing node scripts/smoke.mjs` | 配对预览的设备角色、权限、有效期、取消和重试。 |
| `pnpm verify:local` | 桌面静态检查、单测、构建和十组 Electron 回归，包括独立审批、保险库详情与更新。 |

- `pnpm check` 通过，Svelte 报告 0 错误和 0 警告。`pnpm test` 的 207 项全部通过，无跳过。`pnpm build` 通过，`pnpm audit:controls` 报告 0 项未批准的原生控件。
- 同一组测试数据在修复前后各采集 224 张主窗口截图。四种配置下的 56 个状态全部载入。修复后的主内容区和对话框中，未再测到内容比可横向滚动容器宽出 3 像素以上的情况。独立审批窗口另测到 400 × 560。图集中的 448 张对照图均已逐张解码，另附 22 张专项截图。

- 十组本机 Electron 回归通过。功能回归使用测试 daemon 和系统对话框替身。另以真实 macOS 前台焦点重跑通知，并验证了系统全屏的隐藏与重开。全局快捷键曾在等待进入录制状态时超时，使用可见前台窗口独立复测通过。旧版钱包的两条审批记录用 Rust 测试生成，桌面键盘打开和只读详情回归通过。
