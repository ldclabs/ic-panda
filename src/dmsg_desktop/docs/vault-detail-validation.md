# 保险库条目详情：字段操作与放大查看

日期：2026-11-07。改动基于 `main@b20c7f03`。

## 实现范围

- 字段保留文本选择和直接复制图标，其他操作收进右侧 `…`；右键菜单使用同一组操作。
  选中文字时保留系统文本复制菜单。复制字段值与复制字段引用使用不同反馈。
- 放大查看复用共享 `Dialog`，支持完整长文本、换行、滚动、复制和键盘关闭；
  普通文本按内容决定阅读方向，URL、密钥和验证码保持 LTR。
- 桌面敏感值沿用三秒内再次点击显示、六十秒后隐藏的规则。
  详情行与放大视图共用明文和原始期限，打开弹窗不重置期限或进度条。
  关闭、切换条目、版本变化及锁定会清除明文并忽略迟到读取；同版本同步回执保留视图。
- 验证码放大视图持续刷新，失败可重试；主进程复制的清除时间取剩余有效期与三十秒的较小值，
  扣除请求等待时间。过期回复不会写入剪贴板，后来由用户复制的其他内容不会被定时器清除。
- 保留历史版本只读、受管字段的桌面读取/复制能力，以及钱包、验证码、受管条目、回收站的引用限制。
  冲突时仍禁用字段引用，引用 URI 仍由 daemon 返回。
- 收藏操作进入条目菜单，标题旁显示收藏状态，编辑保持可见；字段标签、工具栏和长值适应窄窗口。
  修复长翻译撑出列表工具栏的问题，并补齐 23 种语言的操作与反馈文案。
