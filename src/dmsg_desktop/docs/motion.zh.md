# 桌面端动效规范

本文件描述小组件的状态动效。曲线和总体规则见 [DESIGN.md 的 Motion 一节](../DESIGN.md#motion)，共享实现在 [motion.ts](../src/renderer/components/motion.ts) 和 [app.css](../src/renderer/app.css)。

## 原则

每个动效只说明一件事：状态变了、位置变了，或者数量变了。动效不做装饰。

七个动词覆盖全部小组件：

| 动词 | 含义 | 时长 · 曲线 |
| --- | --- | --- |
| 落位 | 控件进入新状态，带一点回弹 | 180 ms · spring |
| 滑移 | 选中从一处移到另一处，途经可见 | 220 ms · spring-soft |
| 收放 | 区块展开或收起，下面的内容让位 | 展开 220 ms、收起 140 ms · calm |
| 显影 | 从模糊到清晰；隐藏一律瞬时 | 180 ms · calm |
| 计数 | 数字按位滚动，增加向上、减少向下 | 180 ms · calm |
| 回绝 | 被拒绝时左右摇动；按住提前松开时回退 | 摇动 320 ms；回退 220 ms · calm |
| 指认 | 跳转到的对象或刚保存的字段亮一次 | 900 / 700 ms，淡出 |

时长分五档：

| 档位 | 时长 |
| --- | --- |
| quick | 120 ms |
| exit | 140 ms |
| base | 180 ms |
| move | 220 ms |
| rare | 320 ms |

规则：

1. **越常用越短。** 打字、方向键移动、菜单高亮、拖动不加动效。开关与选择不超过 220 ms，少见的时刻不超过 320 ms。
2. **退出比进入快约三分之一。** 正在退出的元素不接收点击。
3. **揭示可以有过程，隐藏必须立即完成。** 隐藏秘密、锁定一律瞬时。
4. **精确值不补间。** 金额、ID、倒计时只换成最终值。计数按位滚动，每一帧都是真实值。
5. **方向有含义。** 增加向上、减少向下。开关、滑块、翻月、按住填充随阅读方向镜像。
6. **只动 transform、opacity 和 filter。** 例外只有折叠区和提示条的高度、侧栏宽度。
7. **大列表不做行动效。** 超过 100 行时不做行动效。
8. **尊重减弱动态效果。** 系统开启“减弱动态效果”时，所有动效立即完成。

## 开关与复选框

- `Switch`：一项设置现在开着还是关着，拨动立即生效。文字在前，开关在行尾。
- `Checkbox`：多选、确认，以及随表单提交、点“保存”才生效的选项。

## 控件

| 控件 | 动效 | 实现 |
| --- | --- | --- |
| 分段控件 | 选中块滑到新项，文字颜色交接 | `Segmented.svelte`，`motion.ts` 的 `indicator` |
| 标签栏 | 下划线滑到新标签，宽度跟着伸缩 | `page/TabBar.svelte`，`indicator` |
| 复选框 | 底色从中心弹满，对勾一笔画出；取消时对勾先收回 | `Checkbox.svelte`，`app.css` 的 `.check-box` |
| 开关 | 滑钮带回弹滑到另一侧；按住时朝去向拉长；保存失败时滑回 | `Switch.svelte`，`app.css` 的 `.switch` |
| 折叠区 | 高度展开 220 ms，收起 140 ms | `Collapsible.svelte` |
| 键盘焦点环 | 从外侧收拢到控件上，离开时立即消失；方向键移动焦点的组内不收拢 | `app.css` 的 `focus-settle` |
| 菜单 | 从触发点长出，关闭时只淡出 | `ui.ts` 的 `menuContentClass` |
| 提示 | 一次悬停的第一个提示从控件一侧滑入 4px；移到相邻控件时立即出现 | `Tooltip.svelte` |
| 徽标 | 出现时弹出，清零时缩小消失 | `motion.ts` 的 `pop`、`shrink` |
| 计数 | 只滚动变化的那几位：增加从下方进入，减少从上方进入；旧数字立即消失 | `Count.svelte`，`motion.ts` 的 `roll` |
| 复制按钮 | 图标换成对勾 1.2 秒，代替提示条；读屏软件读出“已复制” | `CopyButton.svelte` |
| 密码被拒 | 密码框左右摇动一次，并选中已输入的内容，可以直接重输 | `motion.ts` 的 `shake`，`shell/LocalAccount.svelte` |
| 按住批准 | 提前松开时，填充沿原路退回 | `views/Approval.svelte` |
| 已读回执 | 全部成员送达时画出第二个勾；有人读过后颜色转为森林绿 | `views/channels/Thread.svelte`，`app.css` 的 `.receipt` |

## 不做的

- 菜单项选中时闪一下：每次选择都会多等。
- 纸飞机、撒花、输入时跳动：与平实的语气不符。
- 余额、价格、配额从旧值滚到新值：中间值是假的。
- 悬停时卡片抬起或放大：Mac 的列表行和卡片不会这样。
- 方向键移动时选中底色滑行：键盘导航必须即时。
- 视图之间横向滑动、视差：Mac 窗口里的内容不这样移动。
- 拖动开关的滑钮：点击已经足够。
