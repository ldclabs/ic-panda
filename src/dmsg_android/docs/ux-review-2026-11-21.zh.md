# Android 全页面走查与后续任务

2026-11-21，代码基线为 `8080773d` 加本次工作区改动。对照用户给出的 Android 系统设置、dMsg 截图，以及同一工作区的 iOS 实现。保留四个工作区和 dMsg 的绿色品牌，用 Android 原生分段按钮、浮动操作按钮、列表和返回手势承载操作。按补充参考图，手机底部使用半透明圆角浮条，宽屏使用侧边导航。[iOS 浏览控件](../../dmsg_ios/Features/BrowseBar.swift) · [iOS 会员页](../../dmsg_ios/Features/SubscriptionView.swift) · [Android Material 3](https://developer.android.com/develop/ui/compose/designsystems/material3)

## 六个维度的改动

| 维度 | 用户原来遇到的问题 | 本次修复 |
| --- | --- | --- |
| 信息架构 | 在「会话／信件」或「本机／云备份」间切换后，入口和当前位置难以对应。会员首页与比较页同时列出四档权益。 | 两组同级入口使用相同的分段选择器，经首页进入时保留底部导航。会员首页展示自己可用的权益和用量，所有套餐的逐项权益集中在比较页。 |
| 用户流程 | 创建频道要猜加号，加入要猜箭头。搜索结果为空时缺少下一步。 | 创建频道有具名浮动按钮，加入有文字。无会话时解释如何开始。本机文件无匹配时可以一次清除搜索和收藏条件。 |
| 操作效率 | 文件名、修改时间、大小与收藏看起来是四个同类筛选。保险库的工具栏在窄高窗口一直占用结果区。 | 排序菜单显示当前字段并标记所选项，收藏独立切换。保险库工具栏与结果一起滚动。搜索支持键盘搜索操作和清除。浮条下方可以看见滚动内容，列表底部给末项留出完整空间，软键盘弹出时收起浮条。硬件键盘或触摸探索启用时，自动定位的可见区域截止于浮条上方。 |
| 反馈机制 | 刚进入会员页就可能同时看到加载和不可用提示；上一页的提示会短暂出现在下一页。过期分享任务有时只剩标题。 | 区分读取中、部分成功、过期和失败。重试与错误放在一起。设备与权限同时读取失败且原因相同时，只显示一次说明，重试会重新读取两项。离开页面收起其正在显示的提示。找不到分享任务或收集批次时给出原因和可执行的刷新操作。 |
| 视觉层级 | 账户导航与背景融在一起；普通手机上的会员额度逐个拆成两行。 | 账户身份、身份与安全、同步与存储、设置分组显示。会员首屏优先呈现套餐、额度和用量；行内并列短值，长值自然换行。存储进度使用实际用量上限并计入上传预留。阿拉伯语界面中的数值、单位和额度比例保持阅读顺序。 |
| 组件一致性 | 首页搜索框、语言搜索、时区搜索外观不同，空状态、选项和二级入口节奏不一。 | 复用同一搜索框、列表图标、分组容器、空状态和键值行。分段标签在大字号下换行时，两侧仍等高。系统切换语言并重建界面后，焦点和滚动位置回到语言设置行。新建会话的类型有单选语义和对应说明。浏览器请求在小窗口和大字下可以滚动到最后的动作。 |

## 页面覆盖

逐一核对主路由的 93 个分支。独立 API 36 ARM64 模拟器上的离线样本按下表访问这些分支，并单独打开保险库、会话及文件详情。截图记录的是当次数据状态；同一路由内的弹窗、折叠项和从系统返回的流程还要结合交互回归。依赖外部服务的详情可能停在加载、失败或缺少原记录的状态。

| 操作路径 | 路由 | 检查重点 |
| --- | --- | --- |
| 1. 浏览、编辑和恢复保险库内容 | `vault`、`vault-history`、`vault-version`、`vault-compare`、`conflicts`、`secret-attachments`、`secret-reference`、`secret-health`、`secret-rotation`、`secret-activity`、`vault-import`、`local-import`、`vault-backup` | 搜索、类型、收藏、清除条件、条目标题和秘密字段区分、历史版本与当前版本、操作确认。 |
| 2. 分享保险库条目 | `secret-compose`、`secret-shares`、`secret-share`、`secret-import`、`secret-picker`、`vault-links` | 选择范围、口令输入、分享前的核对、离线记录和无匹配反馈。 |
| 3. 收发消息和管理频道 | `messages`、`inbox`、`invite-letter-sender`、`message-settings`、`inbox-settings`、`blocked-accounts`、`reports`、`report-compose`、`channel-settings`、`channel-setup`、`channel-invite`、`channel-hidden`、`message-reference` | 搜索位置、会话与信件切换、草稿、原消息、创建与加入、举报时的资料披露。 |
| 4. 浏览文件、备份和链接 | `files`、`incoming-shares`、`file-trash`、`file-transfers`、`file-preview`、`cloud-files`、`file-unbacked`、`file-backup`、`file-requests`、`file-request-compose`、`file-request-batch`、`file-links`、`file-link-job`、`file-link-compose`、`backup-link-compose` | 返回原目录、筛选与排序、已核验预览、空文件夹、回收站、云清单完整性、已失效原任务。 |
| 5. 账户、会员与系统设置 | `account`、`profile`、`accounts`、`membership`、`membership-compare`、`sync`、`display-cache`、`account-remove`、`account-delete`、`advanced`、`about`、`privacy`、`feedback`、`system-integrations`、`system-autofill`、`system-files`、`workspace-entries` | 公开资料与权益两个入口、用量及有效期、返回栈、本机移除与服务账户删除的后果。 |
| 6. 设备、授权和提醒 | `security`、`devices`、`recovery`、`recovery-policy`、`bindings`、`hardware`、`pair-approve`、`approvals`、`browser-connections`、`browser-request`、`device-transfer`、`handovers`、`handover-review`、`notifications`、`notification-timezone`、`reminders` | 身份与来源、待审批与已结束、系统权限和应用偏好、时区搜索、手动重试。 |
| 7. Agent 与团队钱包 | `agents`、`agent`、`agent-delegations`、`agent-controller`、`agent-grant`、`wallets`、`wallet`、`wallet-transfer`、`wallet-proposal`、`wallet-controls`、`wallet-cosigners`、`wallet-keys`、`wallet-native-move` | 权限与身份、待审范围、金额与手续费、无权限时的可见动作、服务不可用状态。 |

入口还包括首次使用与锁屏、已有账号登录、本机离线账号、语言选择器、保险库编辑器、文件与相机选择器。Google Play 确认、系统生物识别、跨设备批准等需要外部条件的流程，模拟器样本只能验证客户端界面和状态转换。

## 验证样本

- 中文手机窗口逐一访问上述 93 个工作区路由，另存 3 个实体详情和 5 个锁屏或认证分支。普通 Debug 包另行实测首次使用和设备保护不可用时的反馈。本机账号进入、切换和解锁的正向流程使用测试硬件接口验证；该模拟器未通过真实硬件密钥校验。
- 会员用量采用离线样本。基础存储 100 MiB、实际用量上限 120 MiB、已用 25 MiB、上传预留 5 MiB 时，进度为 25%，剩余 90 MiB。权益过期、用量部分不可用以及比较页另有覆盖。
- 手机浮条的回归检查覆盖四个标签的选中语义、至少 48dp 的触控高度、悬浮操作按钮与导航的间距，以及滚到底后可以点按退出。另在 360dp 宽、200% 字号下检查阿拉伯语的浮条、分段选择和数值方向。手势导航和三键导航均实测了浮条与系统控件的间距。宽屏回归覆盖侧栏、双栏及折叠避让。
- 23 种语言的字符串及通知资源通过完整性检查。逐语言切换、界面重建、返回设置原位及导航方向的设备回归通过。普通包在无锁屏凭据时实际显示「请先在 Android 设置中设置锁屏凭据」。
- 最终源码的 121 项 JVM 单元测试全部通过。API 36 ARM64 设备回归分两组运行，导航及语言组 8 项通过，其余组 113 项通过、7 项因前置条件跳过，总计 128 项、零失败。额外重跑 3 项自动填充界面用例以保存截图，未重复计入总数。
- 跳过项分别涉及真实硬件认证、跨应用自动填充、1 GiB 文件、真实网络、跨端备份互换、五分钟文件授权到期和千条目压力测试。真实 Google Play 交易与双真机交接列入下一轮验收。
- `ProductionNoneDebug` 和 `ProductionGmsDebug` 的 Android Lint 均为零错误，分别报告 63 和 62 条警告，各有 2 条提示。本次产出可安装的 ARM64 `ProductionNoneDebug` APK。
