# รับความช่วยเหลือเกี่ยวกับ dMsg

อัปเดตล่าสุด: 11-10-2569

dMsg สร้างขึ้นในที่สาธารณะโดย ICPanda DAO สำหรับปัญหาที่ทำซ้ำได้ ให้เปิดปัญหา GitHub หากมีคำถาม โปรดถามชุมชน

## สอบถามได้ที่ไหน.

- **รายงานข้อผิดพลาด:** [ปัญหา GitHub](https://github.com/ldclabs/ic-panda/issues) สำหรับปัญหาเกี่ยวกับเว็บไซต์ แอปรุ่นเก่า ส่วนขยาย หรือ canisters
- **คำถามและชุมชน:** [ชุมชน ICPanda บน OpenChat](https://oc.app/community/dqcvf-haaaa-aaaar-a5uqq-cai)
- **ข่าวสารและประกาศ:** [@ICPandaDAO บน X](https://x.com/ICPandaDAO)
- **การเข้าถึง DAO:** [al.ink/ICPanda](https://al.ink/ICPanda)

## แอปรุ่นเก่า

แอปเดิมเป็นแบบอ่านอย่างเดียว ลงชื่อเข้าใช้ด้วยข้อมูลประจำตัวที่มีอยู่ของคุณเพื่ออ่านการสนทนาเก่า ๆ และดาวน์โหลดไฟล์แนบที่คุณสามารถเข้าถึงได้ เก็บเบราว์เซอร์เดิมและข้อมูลไว้ โดยเฉพาะอย่างยิ่งหากคุณใช้โหมดโลคัลคีย์: คีย์ที่จัดเก็บไว้ในเบราว์เซอร์ที่คุณล้างเท่านั้นจะไม่สามารถกู้คืนได้ หากต้องการย้ายไปยัง dMsg ใหม่ ให้ติดตั้งแอปเดสก์ท็อปและเริ่มการย้ายข้อมูลภายใต้การตั้งค่า › ดั้งเดิม; จะเปิดหน้าเดิมของไซต์นี้เพื่อมอบประวัติของคุณไปยังอุปกรณ์นั้น

## การชำระเงินและการสั่งซื้อ

สำหรับการลงทะเบียนชื่อผู้ใช้ วางแผนการซื้อ การต่ออายุ การขอคืนเงินหรือการชำระเงิน ให้ระบุรหัสบัญชีของคุณ รหัสคำสั่งซื้อหรือเอสโครว์ บัญชีแยกประเภทโทเค็น ดัชนีบล็อกธุรกรรม และเวลาโดยประมาณ อย่าชำระเงินอีกเพื่อแก้ไขคำสั่งซื้อที่ล้มเหลว จำนวนเงินที่สามารถขอคืนได้จะกลับไปยังบัญชีที่ชำระเงิน

## สิ่งที่ต้องรวม

- สิ่งที่คุณทำ สิ่งที่คุณคาดหวัง และสิ่งที่เกิดขึ้นแทน
- ข้อความแสดงข้อผิดพลาดที่แน่นอน;
- เบราว์เซอร์ของคุณและเวอร์ชันของมัน และเวอร์ชันส่วนขยายหากคุณใช้งาน
- ภาพหน้าจอโดยลบข้อมูลลับออก

## อย่าเปิดเผยความลับ

อย่าส่งเอกสารการกู้คืน ข้อมูลสำรอง วลีเริ่มต้น คีย์ส่วนตัว ปลดล็อครหัสผ่านหรือเซสชันการเข้าสู่ระบบของคุณให้ใคร และอย่าอนุมัติคำขอที่คุณไม่ได้เริ่ม ฝ่ายสนับสนุน dMsg จะไม่ถามหาสิ่งเหล่านั้น ใครถามไม่รองรับ dMsg
