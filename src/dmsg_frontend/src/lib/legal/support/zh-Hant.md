# 獲取 dMsg 幫助

最後更新：2026-10-11。

dMsg 由 ICPanda DAO 公開開發。可以復現的問題，請提交 GitHub issue；使用上的疑問，請到社區提問。

## 在哪裏提問

- **問題報告**：網站、舊版應用、擴展或 canister 的問題，請提交 [GitHub issue](https://github.com/ldclabs/ic-panda/issues)。
- **疑問與社區**：[OpenChat 上的 ICPanda 社區](https://oc.app/community/dqcvf-haaaa-aaaar-a5uqq-cai)。
- **新聞與公告**：[X 上的 @ICPandaDAO](https://x.com/ICPandaDAO)。
- **聯繫 DAO**：[al.ink/ICPanda](https://al.ink/ICPanda)。

## 舊版應用

舊版應用爲只讀。用原有身份登錄，可以閱讀以前的對話，下載你有權訪問的附件。請保留原來的瀏覽器及其數據，尤其是使用過 Local 密鑰模式的用戶：只保存在已清除的瀏覽器中的密鑰無法找回。要遷移到新版 dMsg，請安裝桌面應用，在“設置 › 舊版遷移”中開始；它會打開本站的舊版頁面，把你的歷史記錄交給這臺設備。

## 付款與訂單

關於用戶名註冊、套餐購買、續期、退款或付費來信的問題，請提供賬戶 ID、訂單或託管 ID、代幣賬本、交易區塊號和大致時間。不要爲了修復失敗的訂單再付一次款。可退金額會退回付款賬戶。

## 請附上這些信息

- 你做了什麼、預期是什麼、實際發生了什麼；
- 完整的錯誤信息；
- 瀏覽器及其版本；如果使用擴展，請附上擴展版本；
- 截圖，並去除其中的任何祕密信息。

## 絕不分享祕密

絕不要把恢復材料、備份、助記詞、私鑰、解鎖密碼或登錄會話發給任何人，也絕不要批准不是你發起的請求。dMsg 支持人員絕不會索要這些信息。索要它們的人都不是 dMsg 支持人員。

## 安全報告

不要在公開 issue 中發佈漏洞細節。請通過 [al.ink/ICPanda](https://al.ink/ICPanda) 私下聯繫我們並附上簡短摘要，我們會安排安全的方式交換細節。
