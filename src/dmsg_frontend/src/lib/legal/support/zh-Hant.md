# 獲取 dMsg 幫助

最後更新：2026-10-11。

dMsg 由 ICPanda DAO 公開開發。可以復現的問題，請提交 GitHub issue；使用上的疑問，請到社群提問。

## 在哪裡提問

- **問題報告**：網站、舊版應用、擴充套件或 canister 的問題，請提交 [GitHub issue](https://github.com/ldclabs/ic-panda/issues)。
- **疑問與社群**：[OpenChat 上的 ICPanda 社群](https://oc.app/community/dqcvf-haaaa-aaaar-a5uqq-cai)。
- **新聞與公告**：[X 上的 @ICPandaDAO](https://x.com/ICPandaDAO)。
- **聯絡 DAO**：[al.ink/ICPanda](https://al.ink/ICPanda)。

## 舊版應用

舊版應用為只讀。用原有身份登入，可以閱讀以前的對話，下載你有權存取的附件。請保留原來的瀏覽器及其資料，尤其是使用過 Local 金鑰模式的使用者：只儲存在已清除的瀏覽器中的金鑰無法找回。要遷移到新版 dMsg，請安裝桌面應用，在「設定 › 舊版遷移」中開始；它會開啟本站的舊版頁面，把你的歷史記錄交給這台裝置。

## 付款與訂單

關於使用者名稱註冊、套餐購買、續期、退款或付費來信的問題，請提供帳戶 ID、訂單或託管 ID、代幣帳本、交易區塊號和大致時間。不要為了修復失敗的訂單再付一次款。可退金額會退回付款帳戶。

## 請附上這些資訊

- 你做了什麼、預期是什麼、實際發生了什麼；
- 完整的錯誤資訊；
- 瀏覽器及其版本；如果使用擴充套件，請附上擴充套件版本；
- 截圖，並去除其中的任何秘密資訊。

## 絕不分享秘密

絕不要把恢復材料、備份、助記詞、私鑰、解鎖密碼或登入會話發給任何人，也絕不要批准不是你發起的請求。dMsg 支援人員絕不會索要這些資訊。索要它們的人都不是 dMsg 支援人員。

## 安全報告

不要在公開 issue 中釋出漏洞細節。請通過 [al.ink/ICPanda](https://al.ink/ICPanda) 私下聯絡我們並附上簡短摘要，我們會安排安全的方式交換細節。
