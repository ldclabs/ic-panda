# Holen Sie sich Hilfe zu dMsg

Letzte Aktualisierung: 11.10.2026.

dMsg wird öffentlich von ICPanda DAO erstellt. Für ein Problem, das Sie reproduzieren können, öffnen Sie ein GitHub-Problem. Bei Fragen wenden Sie sich bitte an die Community.

## Wo man fragen kann

- **Fehlerberichte:** [GitHub-Probleme](https://github.com/ldclabs/ic-panda/issues) für Probleme mit der Website, der Legacy-App, der Erweiterung oder dem canisters.
- **Fragen und Community:** die [ICPanda-Community auf OpenChat](https://oc.app/community/dqcvf-haaaa-aaaar-a5uqq-cai).
- **Neuigkeiten und Ankündigungen:** [@ICPandaDAO auf X](https://x.com/ICPandaDAO).
- **Erreichen des DAO:** [al.ink/ICPanda](https://al.ink/ICPanda).

## Legacy-App

Die Legacy-App ist schreibgeschützt. Melden Sie sich mit Ihrer bestehenden Identität an, um alte Konversationen zu lesen und die Anhänge herunterzuladen, auf die Sie zugreifen können. Behalten Sie den ursprünglichen Browser und seine Daten, insbesondere wenn Sie den lokalen Schlüsselmodus verwendet haben: Schlüssel, die nur in einem von Ihnen gelöschten Browser gespeichert sind, können nicht wiederhergestellt werden. Um zum neuen dMsg zu wechseln, installieren Sie die Desktop-App und starten Sie eine Migration unter Einstellungen › Legacy; Dadurch wird die Legacy-Seite dieser Website geöffnet, um Ihren Verlauf an dieses Gerät zu übertragen.

## Zahlungen und Bestellungen

Geben Sie für eine Handle-Registrierung, einen Plankauf, eine Verlängerung, eine Rückerstattung oder eine kostenpflichtige Anfrage Ihre Konto-ID, die Bestell- oder Treuhand-ID, das Token-Ledger, den Transaktionsblockindex und die ungefähre Zeit an. Senden Sie keine weitere Zahlung, um eine fehlgeschlagene Bestellung zu reparieren. Rückerstattungsbeträge werden auf das Konto zurückerstattet, auf dem die Zahlung erfolgt ist.

## Was enthalten sein soll

- was Sie getan haben, was Sie erwartet haben und was stattdessen passiert ist;
- die genaue Fehlermeldung;
- Ihr Browser und seine Version sowie die Erweiterungsversion, falls Sie ihn verwenden;
- Screenshots, bei denen alle geheimen Informationen entfernt wurden.

## Teilen Sie niemals Geheimnisse

Senden Sie niemals Ihre Wiederherstellungsmaterialien, Backups, Seed-Phrasen, privaten Schlüssel, Entsperrkennwörter oder Anmeldesitzungen an Dritte und genehmigen Sie niemals eine Anfrage, die Sie nicht gestartet haben. Der dMsg-Support wird niemals danach fragen. Wer fragt, ist kein dMsg-Support.

## Sicherheitsberichte

Veröffentlichen Sie keine Details zu Schwachstellen in einer öffentlichen Ausgabe. Kontaktieren Sie uns privat über [al.ink/ICPanda](https://al.ink/ICPanda) mit einer kurzen Zusammenfassung, und wir werden einen sicheren Weg zur Weitergabe der Details vereinbaren.
