# 获取 dMsg 帮助

最后更新：2026-10-11。

dMsg 由 ICPanda DAO 公开开发。可以复现的问题，请提交 GitHub issue；使用上的疑问，请到社区提问。

## 在哪里提问

- **问题报告**：网站、旧版应用、扩展或 canister 的问题，请提交 [GitHub issue](https://github.com/ldclabs/ic-panda/issues)。
- **疑问与社区**：[OpenChat 上的 ICPanda 社区](https://oc.app/community/dqcvf-haaaa-aaaar-a5uqq-cai)。
- **新闻与公告**：[X 上的 @ICPandaDAO](https://x.com/ICPandaDAO)。
- **联系 DAO**：[al.ink/ICPanda](https://al.ink/ICPanda)。

## 旧版应用

旧版应用为只读。用原有身份登录，可以阅读以前的对话，下载你有权访问的附件。请保留原来的浏览器及其数据，尤其是使用过 Local 密钥模式的用户：只保存在已清除的浏览器中的密钥无法找回。迁移到新版 dMsg 的功能尚未开放。

## 付款与订单

关于用户名注册、套餐购买、续期、退款或付费来信的问题，请提供账户 ID、订单或托管 ID、代币账本、交易区块号和大致时间。不要为了修复失败的订单再付一次款。可退金额会退回付款账户。

## 请附上这些信息

- 你做了什么、预期是什么、实际发生了什么；
- 完整的错误信息；
- 浏览器及其版本；如果使用扩展，请附上扩展版本；
- 截图，并去除其中的任何秘密信息。

## 绝不分享秘密

绝不要把恢复材料、备份、助记词、私钥、解锁密码或登录会话发给任何人，也绝不要批准不是你发起的请求。dMsg 支持人员绝不会索要这些信息。索要它们的人都不是 dMsg 支持人员。

## 安全报告

不要在公开 issue 中发布漏洞细节。请通过 [al.ink/ICPanda](https://al.ink/ICPanda) 私下联系我们并附上简短摘要，我们会安排安全的方式交换细节。
