# dMsg 隐私政策

最后更新：2026-10-27。

dMsg 在你授权的设备上加密私密内容。本政策适用于 dmsg.net、只读旧版网页应用、桌面与 iOS 应用、connect.dmsg.net、云端服务和 Internet Computer（ICP）上的 canister。“我们”指在 ICPanda DAO 治理下运营 dMsg 的团队。具体功能是否可用，取决于应用版本与服务配置。

我们不出售个人数据，不把你的内容用于广告；网站没有广告或分析追踪代码。

## 1. 内容与公开信息

保险库条目、私密消息和文件在上传前加密。内容密钥仅保留在授权设备上，或保存在服务无法打开的设备与恢复信封中。接收者可以阅读并保留分享副本。你主动发布的个人档案、头像、名称和目录文档是公开信息。举报属于单独披露：处理人员会收到举报原因、说明、账号及资源标识，以及你明确选择附上的消息正文。举报不会向处理人员提供账号内容密钥。

## 2. 服务元数据

服务处理账号与登录标识、设备公钥、频道成员关系、联系及屏蔽规则、对象大小、请求时间、IP 地址与运行请求信息。经认证的账号状态、签名回执和权益供客户端与服务验证权限。账本交易以及公开或经认证的链上记录通常无法删除。

## 3. Apple 服务与付款

iOS 可选通知使用 Apple 推送通知服务。Apple 与我们的投递服务处理安装标识、设备 token 和投递元数据。通知仅包含通用提醒和不透明的路由标识，不含消息正文、密码或文件名。你可以在 dMsg 或系统设置中关闭通知；已经送达的通知不一定能被收回。

App Attest 使用应用生成的密钥标识、证明和挑战数据验证应用安装。Face ID、Touch ID 与设备密码由操作系统处理；dMsg 不接收生物识别图像或设备密码。

StoreKit 内购由 Apple 处理。我们的验证服务与商业 canister 处理交易和商品标识、账号绑定 token、购买及到期日期、退款与撤销状态，不接收银行卡资料。其他 dMsg 客户端可能支持 ICP 钱包付款和 PANDA 会员，相关账本与权益记录公开可验证。删除 dMsg 账号不会取消 Apple 订阅，请在 Apple 账号中管理订阅。

团队钱包的策略和提案由钱包 canister 处理，可见范围遵循钱包设置。查询余额、估算费用和广播交易时，区块链 RPC 服务会收到所需的地址、交易数据及 IP 信息。默认端点包括 mempool.space、PublicNode、mainnet.base.org 和 api.mainnet-beta.solana.com；另行配置的服务适用其各自隐私政策。

## 4. 本机数据与系统集成

原生应用保存本地加密工作区、在系统支持时由操作系统保护的密钥、草稿、待处理操作及偏好。解锁后，所选内容可在应用内存中使用。导出的文件或复制的文字可能被目标应用保留。

iOS 分享扩展只暂存你选择的内容，随后由你选择账号导入。密码自动填充和 Files 集成只保存明确选择并独立加密的快照。自动填充要求独立的系统认证；快照在 24 小时后到期。Files 访问会话最多持续五分钟，锁定 dMsg 会结束当前会话，但 Files 和其他接收方可能保留已经下载的副本。修改源条目不会自动更新已导出的快照。

明确启动的后台传输只在设备首次解锁后可访问的独立目录中保存有界密文和传输授权，不保存账号签名或内容密钥。验证并完成传输仍须解锁原账号。系统可能延迟或停止传输。

网站在本机记录语言选择。旧版应用使用浏览器存储保存会话和缓存；其钱包视图可能向 ICPSwap 请求价格。移除应用或清除数据可能永久丢失尚未同步或导出的内容。

## 5. 服务提供者与保留

Cloudflare 处理云端密文与请求元数据；ICP 节点及网关运行 canister 和网站；Apple 分发 iOS 应用并提供上述可选服务。Internet Identity、钱包服务和所连接的应用各有隐私政策。法律要求时，我们可能披露持有的信息，包括明确提交的举报；我们无法披露自己并不持有的明文。

云端密文依账号的存储及删除规则保留。删除服务账号是可查询进度的清理请求：阻止新的服务访问、清除账号拥有的云端内容及公开头像副本，并在清理完成后才报告完成。它不会删除他人保留的分享副本、其他设备本机副本、公开账本历史或必要的财务与防重放记录。未结交易或账号拥有的活动频道可能需要先处理。举报记录为人工处理最多保留 90 天；投递 token 未续期会到期。运行日志仅在安全、防滥用与排障需要的期间保留。

## 6. 选择、权利与联系

你可以导出或删除内容、撤销设备或浏览器、屏蔽发送者、举报滥用、修改联系规则、请求删除服务账号，以及单独移除本机账号数据。依所在地法律，你可能享有访问、更正、删除个人信息或反对处理的权利。请通过[支持页面](https://dmsg.net/_/support)提出请求或私下报告漏洞。加密、需保留的交易记录或不可变公开记录限制请求时，我们会说明原因。

任何系统都不可能绝对安全。应用更新和 DAO 治理下的 canister 升级仍是信任环节。dMsg 不面向 13 岁以下儿童，或未达到当地无须监护人同意即可使用在线服务的最低年龄者。政策发生实质变化时，我们会更新日期，并在应用或网站公告。
