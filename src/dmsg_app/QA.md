## 实际浏览器覆盖

测试只使用临时浏览器配置与合成数据：

1. 加载打包扩展并打开全页，创建工作台、下载初始恢复包、验证恢复码。
2. 保存 API 凭据；私密字段默认隐藏，明确确认后显示，再隐藏。
3. 强制停止 Service Worker，页面的 dedicated crypto worker 和已解锁工作台继续可用。
4. 导入文件，校验后下载，核对原始文件字节一致。
5. 锁定后标题和秘密从 DOM 移除；重新解锁可读取原内容。
6. 检查对象、outbox、本地私密数据、密钥封装四类存储中没有测试标题、秘密、文件名、口令或恢复码明文。
7. 初始化恢复检查完成前可在重载或锁定后继续取得加密暂存的恢复码；一般重载仍保持锁定，以 Chrome 文档存活证据回收旧租约，重新输入口令后正常打开。
8. 保存身份资料后停留在身份页锁定、重新解锁，确认表单在显示前已取得原资料。
9. 建立两人会话草稿、保存消息，显示“本地加密草稿 · 未投递”。
10. 重新验证口令后逐块校验并生成完整的本机恢复包；损坏文件块会阻止错误的“完整”导出。在另一个空白浏览器配置中恢复，重新生成设备密钥。
11. 检查 Popup 与 Side Panel HTML 入口；检查 1440px 桌面、390px 和 320px 视口，页面无横向溢出。

桌面秘密库、390px 秘密库、Popup 和 Side Panel 截图已人工查看。所有截图与测试恢复包只留在被忽略的 `test-results/`，不作为真实用户或真实服务的演示证据。

## 限制

没有使用生产账户或真实资产，没有部署/修改 canister 或私有中继，没有执行正式阈值签名。II 派生域与正式扩展 ID、链上设备/恢复授权、候选云端证据互操作、云端频道与文件同步、支付故障矩阵、旧密钥真实样本和容量性能目标仍需专门联调；详细能力边界见 [README](README.md)。

扩展后台不保存内容密钥。页面关闭立即结束其 dedicated Worker；若关闭时 IDB 清理未完成，下一扩展页面结合浏览器文档存活信息和递增租约 fencing token 处理遗留租约。网页开发预览没有 Chrome 文档 API，异常关闭时依赖有界租约到期。
