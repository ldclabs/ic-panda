# Patakaran sa Privacy ng dMsg

Huling na-update: 2026-10-29.

Ine-encrypt ng dMsg ang pribadong content sa iyong mga awtorisadong device. Sinasaklaw ng patakarang ito ang dmsg.net, ang read-only na legacy web app, ang mga desktop at iOS app, ang connect.dmsg.net, ang cloud service, at ang mga canister sa Internet Computer (ICP). Ang ibig sabihin ng “kami” ay ang team na nagpapatakbo ng dMsg sa ilalim ng pamamahala ng ICPanda DAO. Nakadepende sa bersyon ng app at sa configuration ng serbisyo ang pagiging available ng bawat feature.

Hindi kami nagbebenta ng personal na data at hindi namin ginagamit ang iyong content para sa advertising. Walang anumang tracker para sa advertising o analytics ang website.

## 1. Content at pampublikong impormasyon

Ine-encrypt muna ang mga item sa Vault, pribadong mensahe, at file bago i-upload. Mananatili ang mga content key sa mga awtorisadong device o sa mga recovery/device envelope na hindi kayang buksan ng serbisyo. Maaaring basahin at itabi ng mga tatanggap ang mga ibinahaging kopya. Pampubliko ang mga pampublikong profile, avatar, handle (pampublikong username), dokumento sa direktoryo, at impormasyong sadya mong inilalathala. Ang pag-uulat ng pang-aabuso ay isang hiwalay na pagsisiwalat: matatanggap lamang ng mga moderator ang iyong dahilan, tala, identifier ng account/resource, at ang partikular na text ng mensaheng tahasan mong piniling isama. Hindi ibinibigay ng pag-uulat sa mga moderator ang mga key sa iyong account.

## 2. Metadata ng serbisyo

Pinoproseso ng serbisyo ang mga identifier ng account at pag-log in, public key ng device, membership sa channel, panuntunan sa pakikipag-ugnayan at pag-block, laki ng mga object, oras ng kahilingan, IP address, at impormasyon sa pagpapatakbo ng mga kahilingan. Nagbibigay-daan sa mga client app at serbisyo ang sertipikadong estado ng account, mga resibo ng paglagda, at mga karapatan sa paggamit (entitlement) upang ma-verify ang awtoridad. Sa pangkalahatan, hindi na mabubura ang mga transaksyon sa ledger at ang mga pampubliko o sertipikadong on-chain na talaan.

Kung io-on mo ang mga notification, pinoproseso rin ng serbisyo ng notification ang kailangan nito para salain ang mga alerto bago ipadala: mga opaque na identifier ng resource, kung aling mga channel ang na-mute o itinago mo, ang iyong tahimik na oras at time zone, mga resibo ng pagtingin (kung kailan mo talaga tiningnan ang isang paalala at hanggang saang mensahe), at kung aling mga account ang nakarehistro sa iisang installation. Para sa mga paalala ng deadline ng isang nakabinbing pag-recover ng account, ina-upload ng iyong device ang record ng pag-recover, kasama ang bagong login identity at public key ng device; bine-verify ito ng serbisyo at ang paalala at oras ng pagpapatupad lang ang itinatago nito. Hindi natatanggap ng serbisyo ang mga pangalan ng channel, nilalaman ng mensahe o mga key para i-decrypt ang mga ito. Ang pagbawi ng rehistro, pag-alis ng account sa device o pagbura ng service account ay nag-aalis sa mga kagustuhang ito, mga resibo ng pagtingin at mga link ng installation; ang mga record ng paghahatid at muling pagsubok ay itinatago lang hanggang mag-expire ang mga ito.

## 3. Mga serbisyo ng Apple at pagbabayad

Sa iOS, gumagamit ang mga opsyonal na notification ng serbisyo ng Apple Push Notification (APNs). Pinoproseso ng Apple at ng aming serbisyo sa paghahatid ang identifier ng installation, token ng device, at metadata ng paghahatid. Naglalaman lamang ang mga notification ng pangkalahatang paalala at opaque na ruta, at hindi kailanman naglalaman ng katawan ng mensahe, password, o pangalan ng file. Maaari mong i-disable ang mga notification sa dMsg o sa mga setting ng system; hindi sa lahat ng pagkakataon ay mababawi pa ang mga naipadala nang notification. Kung maraming account ang tumatanggap ng notification sa iisang installation, nagbibigay-daan ang pinagsasaluhang device token sa Apple at sa aming serbisyo sa paghahatid na maiugnay ang mga ito; humihingi muna ng pahintulot ang dMsg bago i-on ang mga notification para sa isa pang account.

Pinoproseso ng App Attest ang key identifier na binuo ng app, ebidensya ng attestation/assertion, at mga cryptographic challenge upang ma-verify ang pag-install ng app. Pinangangasiwaan ng operating system ang Face ID, Touch ID, at passcode ng device; hindi natatanggap ng dMsg ang mga biometric na larawan o ang iyong passcode.

Pinangangasiwaan ng Apple ang mga pagbili sa StoreKit. Pinoproseso ng aming verifier at commerce canister ang mga identifier ng transaksyon/produkto, token na nagbubuklod sa account, petsa ng pagbili at pag-expire, at status ng refund/pagbawi. Hindi nila natatanggap ang mga detalye ng iyong payment card. Maaaring suportahan ng iba pang dMsg client ang mga pagbabayad gamit ang ICP wallet at membership sa PANDA, na may pampublikong ledger at talaan ng mga karapatan. Hindi nakakansela ang subscription sa Apple kapag binura ang dMsg account; pamahalaan ang iyong mga subscription sa iyong Apple Account.

Pinoproseso ng mga wallet canister ang mga patakaran at panukala ng multisig wallet; sumusunod ang visibility ng mga ito sa mga setting ng wallet. Natatanggap ng mga blockchain RPC provider ang mga address, data ng transaksyon, at impormasyon ng IP na kailangan para sa pagtatanong ng balanse, simulation ng bayarin, at pag-broadcast ng transaksyon. Kabilang sa mga default na endpoint ang mempool.space, PublicNode, mainnet.base.org, at api.mainnet-beta.solana.com; may sariling mga patakaran sa privacy ang mga alternatibong endpoint na ikaw mismo ang nag-configure.

## 4. Lokal na data at mga integrasyon sa system

Nagpapanatili ang mga native na app ng lokal na naka-encrypt na workspace, mga key na pinoprotektahan ng operating system (kung saan sinusuportahan), mga draft, mga nakabinbing operasyon, at mga kagustuhan. Ginagawang available ng pag-unlock ang napiling content sa memorya ng app. Maaaring mapanatili ng mga patutunguhang app ang mga na-export na file at kinopyang text.

Inihahanda lamang ng Share extension ng iOS ang mga item na pinili mo para sa pag-import sa account sa ibang pagkakataon. Naglalaman lamang ang mga integrasyon ng Password AutoFill at Files app ng mga tahasang pinili at hiwalay na naka-encrypt na snapshot. Nangangailangan ang AutoFill ng hiwalay na pagpapatunay ng system; nag-e-expire ang mga snapshot pagkalipas ng 24 na oras. Tumatagal nang hanggang limang minuto lamang ang mga session ng pag-access sa Files app at nagtatapos kapag nag-lock ang dMsg, ngunit maaaring mapanatili ng Files app at ng iba pang tatanggap ang mga kopyang na-download na. Hindi awtomatikong ina-update ng pagbabago sa mga orihinal na item ang na-export nang snapshot.

Nag-iimbak lamang ang mga tahasang sinimulang paglilipat sa background ng limitadong ciphertext at awtoridad sa paglilipat sa isang hiwalay na direktoryo ng device na maa-access pagkatapos ng unang pag-unlock sa device. Wala itong hawak na mga key sa paglagda ng account o content key. Dapat i-unlock ang orihinal na account upang ma-verify at makumpleto ang paglilipat. Maaaring maantala o ihinto ng operating system ang paghahatid.

Tinandaan ng website nang lokal ang pinili mong wika. Gumagamit ang legacy web app ng storage ng browser para sa mga session at naka-cache na data; maaaring humiling ng mga presyo mula sa ICPSwap ang wallet view nito. Maaaring permanenteng mawala ang content na hindi kailanman na-sync o na-export kapag inalis ang app o nilinis ang data nito.

## 5. Mga provider at pagpapanatili ng data

Pinoproseso ng Cloudflare ang cloud ciphertext at metadata ng kahilingan. Pinapatakbo ng mga ICP node provider at gateway ang mga canister at website. Ipinapamahagi ng Apple ang iOS app at ibinibigay ang mga opsyonal na serbisyong inilarawan sa itaas. May kani-kanilang patakaran sa privacy ang Internet Identity, mga wallet provider, at mga nakakonektang application. Maaari naming isiwalat ang impormasyong hawak namin kapag iniaatas ng batas, kabilang ang mga tahasang isinumiteng ulat; hindi namin maisisiwalat ang plaintext na wala sa amin.

Sumusunod ang cloud ciphertext sa mga panuntunan sa pag-iimbak at pagbura ng account. Ang pagbura ng service account ay isang sinusubaybayang kahilingan sa paglilinis: hinaharangan nito ang bagong access sa serbisyo, inaalis ang cloud content na pagmamay-ari ng account at mga pampublikong kopya ng avatar, at nag-uulat lamang ng pagkumpleto pagkatapos ng paglilinis. Hindi nito binubura ang mga kopyang ibinahagi sa ibang tao, mga lokal na kopya sa iba pang device, kasaysayan sa pampublikong ledger, o kinakailangang talaan sa pananalapi at anti-replay. Maaaring kailanganin munang tapusin ang mga hindi pa naaayos na transaksyon o mga aktibong channel na pagmamay-ari mo. Pinananatili nang hanggang 90 araw ang mga talaan ng ulat para sa pagsusuri; nag-e-expire ang mga delivery token maliban kung nire-renew. Pinananatili lamang ang mga operational log hangga't kinakailangan para sa seguridad, pag-iwas sa pang-aabuso, at pag-troubleshoot.

## 6. Mga pagpipilian, karapatan, at pakikipag-ugnayan

Maaari kang mag-export o magbura ng content, bumawi ng pahintulot sa mga device o browser, mag-block ng mga nagpadala, mag-ulat ng pang-aabuso, magbago ng mga panuntunan sa pakikipag-ugnayan, humiling ng pagbura ng service account, at hiwalay na mag-alis ng data ng account sa device na ito. Depende sa iyong lokasyon, maaaring may karapatan kang i-access, itama, burahin, o tutulan ang pagproseso ng personal na impormasyon. Makipag-ugnayan sa [Support](https://dmsg.net/_/support) para sa mga kahilingan o pribadong ulat ng kahinaan sa seguridad. Ipapaliwanag namin kapag nililimitahan ng encryption, mga pinananatiling talaan ng transaksyon, o mga hindi nababagong pampublikong talaan ang isang kahilingan.

Walang sistemang ganap na ligtas. Nananatiling mga punto ng pagtitiwala ang mga update sa app at pag-upgrade ng canister sa ilalim ng pamamahala ng DAO. Hindi inilaan ang dMsg para sa mga batang wala pang 13 taong gulang o mas mababa sa naaangkop na minimum na edad para sa paggamit ng mga online na serbisyo nang walang pahintulot ng magulang. Ina-update namin ang petsa sa itaas at inaanunsyo sa app o sa website ang mahahalagang pagbabago sa patakaran.
