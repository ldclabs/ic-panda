# dMsg プライバシー ポリシー

最終更新日: 2026-10-29。

dMsg は、認証されたデバイス上のプライベート コンテンツを暗号化します。このポリシーは、読み取り専用のレガシー Web アプリである dmsg.net、デスクトップおよび iOS アプリ、connect.dmsg.net、クラウド サービス、およびインターネット コンピューター (ICP) canisters を対象としています。 「私たち」とは、ICPanda DAO ガバナンスの下で dMsg を運営するチームを意味します。個々の機能が利用できるかどうかは、アプリのバージョンとサービス構成によって異なります。

当社は個人データを販売したり、お客様のコンテンツを広告に使用したりすることはありません。 Web サイトには広告や分析トラッカーは含まれていません。

## 1. コンテンツと公開情報

Vault アイテム、プライベート メッセージ、ファイルはアップロード前に暗号化されます。コンテンツ キーは、承認されたデバイス上、またはサービスが開くことができないリカバリ/デバイス エンベロープ内に残ります。受信者は共有コピーを読み取って保持できます。公開プロフィール、アバター、ハンドル、ディレクトリ文書、および意図的に公開した情報は公開されます。レポートは別個の開示です。モデレーターは、理由、メモ、アカウント/リソースの識別子、および含めることを明示的に選択したメッセージ テキストのみを受け取ります。報告によってモデレータにアカウントのキーが与えられることはありません。

## 2. サービスのメタデータ

このサービスは、アカウントとログインの識別子、デバイスの公開キー、チャネルのメンバーシップ、連絡先とブロックのルール、オブジェクトのサイズ、リクエストのタイミング、IP アドレス、操作リクエスト情報を処理します。認証されたアカウントの状態、署名の受領書、資格により、クライアントとサービスは権限を検証できます。台帳トランザクションおよび公開または認証されたオンチェーン記録は通常、消去できません。

通知をオンにすると、通知サービスは送信前にアラートを絞り込むために必要な次の情報も処理します: 不透明なリソース ID、ミュートまたは非表示にしたチャネル、通知停止時間とタイムゾーン、閲覧記録 (リマインダーを実際に確認した時刻とどのメッセージまで読んだか)、同じインストールに登録されているアカウント。保留中のアカウント復旧について期限のリマインダーを送るため、デバイスは新しいログイン ID とデバイスの公開キーを含む復旧記録をアップロードします。サービスはそれを検証し、リマインダーと実行時刻のみを保持します。サービスはチャネル名、メッセージの内容、それらを復号するキーを受け取りません。登録の取り消し、デバイスからのアカウントの削除、サービス アカウントの削除を行うと、これらの設定、閲覧記録、インストールとの関連付けは消去されます。配信と再試行の記録は有効期限まで保持されます。

## 3. Apple のサービスと支払い

iOS では、オプションの通知は Apple プッシュ通知サービスを使用します。 Apple と当社の配信サービスは、インストール ID、デバイス トークン、および配信メタデータを処理します。通知には、メッセージ本文、パスワード、ファイル名ではなく、一般的なリマインダーと不透明なルートが含まれます。 dMsg またはシステム設定で通知を無効にすることができます。すでに配信された通知をいつでも呼び出せるわけではありません。1 つのインストールで複数のアカウントが通知を受け取る場合、共通のデバイス トークンにより Apple と当社の配信サービスはそれらを関連付けることができます。別のアカウントの通知をオンにする前に、dMsg は確認を求めます。

App Attest は、アプリが生成したキー識別子、アテステーション/アサーション証拠、およびチャレンジを処理して、アプリのインストールを検証します。 Face ID、Touch ID およびデバイスのパスコードはオペレーティング システムによって処理されます。 dMsg は生体認証画像やパスコードを受信しません。

StoreKit の購入は Apple によって処理されます。当社の検証者とコマース canister は、トランザクション/製品 ID、アカウント バインディング トークン、購入日と有効期限、返金/取り消しステータスを処理します。彼らはあなたの支払いカードの詳細を受け取りません。他の dMsg クライアントは、公開台帳と資格記録を備えた ICP ウォレット支払いと PANDA メンバーシップをサポートする場合があります。アカウントを削除しても Apple サブスクリプションはキャンセルされません。 Apple アカウントでサブスクリプションを管理します。

チームウォレットのポリシーと提案はウォレット canisters によって処理されます。それらの可視性はウォレットの設定に従います。ブロックチェーン RPC プロバイダーは、残高照会、料金シミュレーション、ブロードキャストに必要なアドレス、トランザクション データ、IP 情報を受け取ります。デフォルトのエンドポイントには、mempool.space、PublicNode、mainnet.base.org、および api.mainnet-beta.solana.com が含まれます。構成された代替案には独自のプライバシー慣行があります。

## 4. ローカル データとシステムの統合

ネイティブ アプリは、ローカルの暗号化されたワークスペース、サポートされているオペレーティング システムによって保護されたキー、ドラフト、保留中の操作、および設定を保持します。ロックを解除すると、選択したコンテンツがアプリのメモリで利用できるようになります。エクスポートされたファイルとコピーされたテキストは、宛先アプリによって保持される場合があります。

iOS 共有拡張機能は、後でアカウントをインポートするために選択したアイテムのみをステージングします。パスワードの自動入力とファイルの統合には、明示的に選択され、個別に暗号化されたスナップショットのみが含まれます。自動入力には独立したシステム認証が必要です。スナップショットは 24 時間後に期限切れになります。ファイル アクセス セッションは最長 5 分間継続し、dMsg がロックされると終了しますが、ファイル アプリと他の受信者はダウンロード済みのコピーを保持する可能性があります。ソース項目を変更しても、エクスポートされたスナップショットは自動的には更新されません。

明示的なバックグラウンド転送では、制限された暗号文のみが保存され、最初のデバイスのロック解除後にアクセスできる別のデバイス ディレクトリに権限が転送されます。アカウント署名やコンテンツ キーは保持しません。転送を確認して完了するには、元のアカウントのロックを解除する必要があります。システムの都合上、配信が遅れたり、停止したりする場合がございます。

ウェブサイトはあなたの言語をローカルに記憶します。従来のアプリは、セッションとキャッシュされたデータにブラウザー ストレージを使用します。そのウォレット ビューは ICPSwap から価格を要求する場合があります。アプリを削除したり、そのデータを消去すると、同期またはエクスポートされていないコンテンツが永久に失われる可能性があります。

## 5. サービス提供者とデータの保存

Cloudflare はクラウド暗号文を処理し、メタデータを要求します。 ICP ノードプロバイダーとゲートウェイは、canisters と Web サイトを運営します。 Apple は iOS アプリを配布し、上記のオプション サービスを提供します。 Internet Identity、ウォレットプロバイダーと接続アプリケーションには独自のプライバシーポリシーがあります。当社は、法的に要求された場合、明示的に提出されたレポートなど、当社が保有する情報を開示する場合があります。私たちが所有していない平文を公開することはできません。

クラウド暗号文は、アカウントの保存および削除ルールに従います。サービス アカウントの削除は追跡されたクリーンアップ リクエストです。新しいサービス アクセスをブロックし、アカウント所有のクラウド コンテンツとパブリック アバターのコピーを削除し、クリーンアップ後にのみ完了を報告します。他の人の共有コピー、他のデバイス上のローカルコピー、公開台帳の履歴、または必要な財務/アンチリプレイ記録は消去されません。未決済のトランザクションまたは所有されているアクティブなチャネルは、最初に解決する必要がある場合があります。レポート記録はレビューのために最大 90 日間保存されます。配信トークンは更新しない限り有効期限が切れます。操作ログは、セキュリティ、悪用防止、トラブルシューティングのために必要な場合にのみ保存されます。

## 6. 選択、権利、連絡先

コンテンツのエクスポートまたは削除、デバイスまたはブラウザの取り消し、送信者のブロック、不正行為の報告、連絡先ルールの変更、サービス アカウントの削除のリクエスト、このデバイスのアカウント データの個別の削除を行うことができます。お住まいの地域によっては、個人情報にアクセス、修正、削除、または処理に異議を唱える権利がある場合があります。リクエストまたは非公開の脆弱性レポートについては、[サポート](https://dmsg.net/_/support) にお問い合わせください。暗号化、保持されるトランザクション記録、または不変の公的記録がリクエストを制限する場合について説明します。

完全に安全なシステムはありません。 DAO ガバナンスに基づくアプリの更新と canister アップグレードは、信頼ポイントのままです。 dMsg は、13 歳未満、または保護者の同意なしにオンライン サービスを使用できる最低年齢に満たないお子様を対象としていません。上記の日付を更新し、アプリまたはウェブサイトで重大なポリシーの変更を発表します。
