# dMsg 隱私政策

最後更新：2026-10-27。

dMsg 在你授權的設備上加密私密內容。本政策適用於 dmsg.net、只讀舊版網頁應用、桌面與 iOS 應用、connect.dmsg.net、雲端服務和 Internet Computer（ICP）上的 canister。“我們”指在 ICPanda DAO 治理下運營 dMsg 的團隊。具體功能是否可用，取決於應用版本與服務配置。

我們不出售個人數據，不把你的內容用於廣告；網站沒有廣告或分析追蹤代碼。

## 1. 內容與公開信息

保險庫條目、私密消息和文件在上傳前加密。內容密鑰僅保留在授權設備上，或保存在服務無法打開的設備與恢復信封中。接收者可以閱讀並保留分享副本。你主動發佈的個人檔案、頭像、名稱和目錄文檔是公開信息。舉報屬於單獨披露：處理人員會收到舉報原因、說明、賬號及資源標識，以及你明確選擇附上的消息正文。舉報不會向處理人員提供賬號內容密鑰。

## 2. 服務元數據

服務處理賬號與登錄標識、設備公鑰、頻道成員關係、聯繫及屏蔽規則、對象大小、請求時間、IP 地址與運行請求信息。經認證的賬號狀態、簽名回執和權益供客戶端與服務驗證權限。賬本交易以及公開或經認證的鏈上記錄通常無法刪除。

## 3. Apple 服務與付款

iOS 可選通知使用 Apple 推送通知服務。Apple 與我們的投遞服務處理安裝標識、設備 token 和投遞元數據。通知僅包含通用提醒和不透明的路由標識，不含消息正文、密碼或文件名。你可以在 dMsg 或系統設置中關閉通知；已經送達的通知不一定能被收回。

App Attest 使用應用生成的密鑰標識、證明和挑戰數據驗證應用安裝。Face ID、Touch ID 與設備密碼由操作系統處理；dMsg 不接收生物識別圖像或設備密碼。

StoreKit 內購由 Apple 處理。我們的驗證服務與商業 canister 處理交易和商品標識、賬號綁定 token、購買及到期日期、退款與撤銷狀態，不接收銀行卡資料。其他 dMsg 客戶端可能支持 ICP 錢包付款和 PANDA 會員，相關賬本與權益記錄公開可驗證。刪除 dMsg 賬號不會取消 Apple 訂閱，請在 Apple 賬號中管理訂閱。

團隊錢包的策略和提案由錢包 canister 處理，可見範圍遵循錢包設置。查詢餘額、估算費用和廣播交易時，區塊鏈 RPC 服務會收到所需的地址、交易數據及 IP 信息。默認端點包括 mempool.space、PublicNode、mainnet.base.org 和 api.mainnet-beta.solana.com；另行配置的服務適用其各自隱私政策。

## 4. 本機數據與系統集成

原生應用保存本地加密工作區、在系統支持時由操作系統保護的密鑰、草稿、待處理操作及偏好。解鎖後，所選內容可在應用內存中使用。導出的文件或複製的文字可能被目標應用保留。

iOS 分享擴展只暫存你選擇的內容，隨後由你選擇賬號導入。密碼自動填充和 Files 集成只保存明確選擇並獨立加密的快照。自動填充要求獨立的系統認證；快照在 24 小時後到期。Files 訪問會話最多持續五分鐘，鎖定 dMsg 會結束當前會話，但 Files 和其他接收方可能保留已經下載的副本。修改源條目不會自動更新已導出的快照。

明確啓動的後臺傳輸只在設備首次解鎖後可訪問的獨立目錄中保存有界密文和傳輸授權，不保存賬號簽名或內容密鑰。驗證並完成傳輸仍須解鎖原賬號。系統可能延遲或停止傳輸。

網站在本機記錄語言選擇。舊版應用使用瀏覽器存儲保存會話和緩存；其錢包視圖可能向 ICPSwap 請求價格。移除應用或清除數據可能永久丟失尚未同步或導出的內容。

## 5. 服務提供者與保留

Cloudflare 處理雲端密文與請求元數據；ICP 節點及網關運行 canister 和網站；Apple 分發 iOS 應用並提供上述可選服務。Internet Identity、錢包服務和所連接的應用各有隱私政策。法律要求時，我們可能披露持有的信息，包括明確提交的舉報；我們無法披露自己並不持有的明文。

雲端密文依賬號的存儲及刪除規則保留。刪除服務賬號是可查詢進度的清理請求：阻止新的服務訪問、清除賬號擁有的雲端內容及公開頭像副本，並在清理完成後才報告完成。它不會刪除他人保留的分享副本、其他設備本機副本、公開賬本歷史或必要的財務與防重放記錄。未結交易或賬號擁有的活動頻道可能需要先處理。舉報記錄爲人工處理最多保留 90 天；投遞 token 未續期會到期。運行日誌僅在安全、防濫用與排障需要的期間保留。

## 6. 選擇、權利與聯繫

你可以導出或刪除內容、撤銷設備或瀏覽器、屏蔽發送者、舉報濫用、修改聯繫規則、請求刪除服務賬號，以及單獨移除本機賬號數據。依所在地法律，你可能享有訪問、更正、刪除個人信息或反對處理的權利。請通過[支持頁面](https://dmsg.net/_/support)提出請求或私下報告漏洞。加密、需保留的交易記錄或不可變公開記錄限制請求時，我們會說明原因。

任何系統都不可能絕對安全。應用更新和 DAO 治理下的 canister 升級仍是信任環節。dMsg 不面向 13 歲以下兒童，或未達到當地無須監護人同意即可使用在線服務的最低年齡者。政策發生實質變化時，我們會更新日期，並在應用或網站公告。
