# dMsg 隱私政策

最後更新：2026-10-29。

dMsg 在你授權的裝置上加密私密內容。本政策適用於 dmsg.net、只讀舊版網頁應用、桌面與 iOS 應用、connect.dmsg.net、雲端服務和 Internet Computer（ICP）上的 canister。「我們」指在 ICPanda DAO 治理下運營 dMsg 的團隊。具體功能是否可用，取決於應用版本與服務配置。

我們不出售個人資料，不把你的內容用於廣告；網站沒有廣告或分析追蹤程式碼。

## 1. 內容與公開資訊

保險庫條目、私密訊息和檔案在上傳前加密。內容金鑰僅保留在授權裝置上，或儲存在服務無法開啟的裝置與恢復信封中。接收者可以閱讀並保留分享副本。你主動釋出的個人檔案、頭像、名稱和目錄文件是公開資訊。舉報屬於單獨披露：處理人員會收到舉報原因、說明、帳號及資源標識，以及你明確選擇附上的訊息正文。舉報不會向處理人員提供帳號內容金鑰。

## 2. 服務後設資料

服務處理帳號與登入標識、裝置公鑰、頻道成員關係、聯絡及封鎖規則、物件大小、請求時間、IP 地址與執行請求資訊。經認證的帳號狀態、簽名回執和權益供客戶端與服務驗證權限。帳本交易以及公開或經認證的鏈上記錄通常無法刪除。

開啟通知後，通知服務還會處理在傳送前過濾提醒所需的資訊：不透明的資源標識、你靜音或隱藏的頻道、勿擾時段與時區、查看回執（你實際查看提醒的時間，以及看到哪則訊息），以及同一安裝登記了哪些帳號。為在帳號復原待執行時依期限提醒你，你的裝置會上傳該復原記錄，其中包含新的登入身分和裝置公鑰；服務核驗後只保留該提醒及其執行時間。服務不會取得頻道名稱、訊息內容或解密金鑰。撤銷登記、從裝置移除帳號或刪除服務帳號時，會清除這些偏好、查看回執與安裝關聯；投遞與重試記錄只保留到其有效期結束。

## 3. Apple 服務與付款

iOS 可選通知使用 Apple 推送通知服務。Apple 與我們的投遞服務處理安裝標識、裝置 token 和投遞後設資料。通知僅包含通用提醒和不透明的路由標識，不含訊息正文、密碼或檔名。你可以在 dMsg 或系統設定中關閉通知；已經送達的通知不一定能被收回。同一安裝為多個帳號接收通知時，共用的裝置 token 會讓 Apple 和我們的投遞服務得以關聯這些帳號；為另一個帳號開啟通知前，dMsg 會先徵得你的同意。

App Attest 使用應用生成的金鑰標識、證明和挑戰資料驗證應用安裝。Face ID、Touch ID 與裝置密碼由作業系統處理；dMsg 不接收生物識別影像或裝置密碼。

StoreKit 內購由 Apple 處理。我們的驗證服務與商業 canister 處理交易和商品標識、帳號繫結 token、購買及到期日期、退款與撤銷狀態，不接收銀行卡資料。其他 dMsg 客戶端可能支援 ICP 錢包付款和 PANDA 會員，相關帳本與權益記錄公開可驗證。刪除 dMsg 帳號不會取消 Apple 訂閱，請在 Apple 帳號中管理訂閱。

團隊錢包的策略和提案由錢包 canister 處理，可見範圍遵循錢包設定。查詢餘額、估算費用和廣播交易時，區塊鏈 RPC 服務會收到所需的地址、交易資料及 IP 資訊。預設端點包括 mempool.space、PublicNode、mainnet.base.org 和 api.mainnet-beta.solana.com；另行配置的服務適用其各自隱私政策。

## 4. 本機資料與系統整合

原生應用儲存本機加密工作區、在系統支援時由作業系統保護的金鑰、草稿、待處理操作及偏好。解鎖後，所選內容可在應用記憶體中使用。匯出的檔案或複製的文字可能被目標應用保留。

iOS 分享擴充套件只暫存你選擇的內容，隨後由你選擇帳號匯入。密碼自動填充和 Files 整合只儲存明確選擇並獨立加密的快照。自動填充要求獨立的系統認證；快照在 24 小時後到期。Files 存取會話最多持續五分鐘，鎖定 dMsg 會結束當前會話，但 Files 和其他接收方可能保留已經下載的副本。修改源條目不會自動更新已匯出的快照。

明確啟動的背景傳輸只在裝置首次解鎖後可存取的獨立目錄中儲存有界密文和傳輸授權，不儲存帳號簽名或內容金鑰。驗證並完成傳輸仍須解鎖原帳號。系統可能延遲或停止傳輸。

網站在本機記錄語言選擇。舊版應用使用瀏覽器儲存儲存會話和快取；其錢包檢視可能向 ICPSwap 請求價格。移除應用或清除資料可能永久丟失尚未同步或匯出的內容。

## 5. 服務提供者與保留

Cloudflare 處理雲端密文與請求後設資料；ICP 節點及閘道器執行 canister 和網站；Apple 分發 iOS 應用並提供上述可選服務。Internet Identity、錢包服務和所連線的應用各有隱私政策。法律要求時，我們可能披露持有的資訊，包括明確提交的舉報；我們無法披露自己並不持有的明文。

雲端密文依帳號的儲存及刪除規則保留。刪除服務帳號是可查詢進度的清理請求：阻止新的服務存取、清除帳號擁有的雲端內容及公開頭像副本，並在清理完成後才報告完成。它不會刪除他人保留的分享副本、其他裝置本機副本、公開帳本歷史或必要的財務與防重放記錄。未結交易或帳號擁有的活動頻道可能需要先處理。舉報記錄為人工處理最多保留 90 天；投遞 token 未續期會到期。執行日誌僅在安全、防濫用與排障需要的期間保留。

## 6. 選擇、權利與聯絡

你可以匯出或刪除內容、撤銷裝置或瀏覽器、封鎖傳送者、舉報濫用、修改聯絡規則、請求刪除服務帳號，以及單獨移除本機帳號資料。依所在地法律，你可能享有存取、更正、刪除個人資訊或反對處理的權利。請通過[支援頁面](https://dmsg.net/_/support)提出請求或私下報告漏洞。加密、需保留的交易記錄或不可變公開記錄限制請求時，我們會說明原因。

任何系統都不可能絕對安全。應用更新和 DAO 治理下的 canister 升級仍是信任環節。dMsg 不面向 13 歲以下兒童，或未達到當地無須監護人同意即可使用線上服務的最低年齡者。政策發生實質變化時，我們會更新日期，並在應用或網站公告。
