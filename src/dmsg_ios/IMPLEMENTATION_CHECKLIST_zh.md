# iOS 修复与能力交付清单

更新：2026-10-27。按代码、自动验证和发布前外部配置分别记录，避免将源码实现当成已上线。

## 已落地的修复与优化

- [x] 统一手动／自动同步；活动频道优先，失败不饿死其他频道。
- [x] 按账号、会话和请求代次拒绝迟到结果；锁定不等待网络。
- [x] 发送保留原编号，只有提交的草稿被清除；最新草稿在锁定前批量落盘。
- [x] 保险库先过滤再分页；收藏独立读取；聊天刷新保留已加载历史和阅读位置。
- [x] 图片像素、输入和并发预算；头像缩略图异步解码与缓存。
- [x] 文件／密码导入恢复、共享条目和导入完成凭据，取消后保留可恢复状态。
- [x] 原生只读预览、临时文件清理、垃圾维护、版本恢复、重命名和移动。
- [x] 公开资料版本检查、头像发布与原发布重试；读取尚未完成目录发布的最新主页状态。
- [x] 消息搜索、回复、编辑、撤回，频道角色、密钥轮换许可、离开与归档。
- [x] 免费来信发送、原来信恢复和免费收信规则；付费发送按决定关闭。
- [x] 生成库、Swift 绑定、源码依赖闭包与构建 profile 校验；归档使用优化 Rust。
- [x] 六种语言界面、通用推送文案、离线隐私政策及编译器提取覆盖检查。

## 已落地的原生能力

- [x] APNs 登记／注销、冷启动路由、失效 token 和设备撤销处理。
- [x] App Attest 挑战、登记、断言、重放防护、设备变更与丢失回包恢复。
- [x] StoreKit 商品、购买前校验、购买／恢复／更新；服务验证及 commerce 权威权益。
- [x] 订阅续订、退款、撤销、原交易幂等、短期权益租约与沙盒隔离。
- [x] 团队钱包查看、加入、地址／成员／阈值／协签提案、转账、批准、冻结、执行与原交易广播。
- [x] 钱包硬件协签、未决提案恢复，并区分明确拒绝和未知结果。
- [x] Agent 身份、权限、controller 与 delegation 管理。
- [x] Share、AutoFill、只读 File Provider 与认证 UI、Widget、App Intents。
- [x] 浏览器配对、universal-link 导航和切换回浏览器后的原操作恢复。
- [x] 有界后台密文 URLSession 传输；解密校验与正式提交只在原账号解锁后进行。
- [x] 永久关闭服务账号及可追踪清理、举报／屏蔽、人工举报处理接口。
- [x] 公开本地演示、真实审核登录说明、六语言隐私政策与隐私清单。
- [x] TestFlight 固定连接线上服务，测试人员通过自己的 passkey 自助注册；当前构建关闭内购入口、恢复及全部 StoreKit 交易处理，仍可查看已有套餐与用量。

钱包新建遵守产品已存在的新建暂停；没有绕过独立 ICP 激活合同。iOS 不作为常驻 Agent daemon。connect 的注册 redirect-URI 新协议模式不等同于本轮已完成的 App 唤起导航，仍遵守原合同范围。
